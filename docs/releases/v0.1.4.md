Cursor Dictation 0.1.4 adds Markdown saving and updates recording controls and Settings.

## Added

- Hold `Ctrl+Alt+M` while you speak. Release M to save the text as a new Markdown file.
- Choose a destination folder and optional YAML properties in Settings > Markdown.
- Each saved file has a date and time in its name. Existing files are not overwritten.
- Use the new Record to Markdown tray command to start and stop a recording.
- The status display shows SAVED after a successful save. If saving fails, use Copy recovered
  text in the tray to recover the transcript.

## Changed

- `Ctrl+Alt+C` now records while you hold it. Release C to transcribe and copy the text.
- Insert, copy, and Markdown shortcuts use the same hold and release controls.
- `Ctrl+Alt+D` remains the shortcut to start and stop recording for text insertion.
- Dictation stays available while Settings is open. Saving Settings is blocked during dictation.
- Recording stops an active microphone test. Model changes must finish before recording starts.
- Settings now uses the selected Warm White or Chamber colors, with a live color preview and
  updated checkboxes.
- Opening Settings from the tray restores the window and brings it to the front.

## Install

Download the ZIP and its `.sha256` file. Verify the ZIP checksum, then extract the complete
`Cursor Dictation` folder. Run `Cursor Dictation.exe`. Keep the adjacent `_internal` folder
beside the executable.

The executable is not code-signed, so Windows may show a SmartScreen warning.
