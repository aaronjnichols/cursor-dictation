Cursor Dictation 0.1.3 cleans up error notifications.

## Changed

- Empty recordings now show `NO SPEECH DETECTED` with a clear `TRY AGAIN` action.
- Error notifications dismiss automatically after five seconds.
- Added a close button for dismissing an error immediately.
- Long internal error messages now use compact display text instead of clipping outside the card.
- Recoverable transcript actions remain available from the tray after the notification closes.
- Extended overlay screenshot generation to include the error state.

## Install

Download both release files and verify the ZIP against the `.sha256` file. Extract the complete
`Cursor Dictation` folder, then run `Cursor Dictation.exe`. Keep the adjacent `_internal` folder
beside the executable.

The executable is not code-signed, so Windows may show a SmartScreen warning.
