Cursor Dictation 0.1.1 is the first downloadable Windows release.

## Included

- Local Whisper `small.en` transcription with CPU inference and no cloud fallback.
- Hold-to-talk, toggle-to-record, record-and-copy, and cancel shortcuts.
- Direct insertion at the active cursor with clipboard restoration.
- Microphone selection and input testing, personal vocabulary, optional transcript history, and
  launch-at-sign-in settings.
- Compact status overlay with a live block meter, stable transcription animation, and pixel check
  completion indicator using the OpenChamber-inspired palette.
- Verified one-folder Windows package with runtime licenses and a SHA-256 checksum.

## Install

Download both release files and verify the ZIP against the `.sha256` file. Extract the complete
`Cursor Dictation` folder, then run `Cursor Dictation.exe`. The adjacent `_internal` folder must
remain beside the executable.

On first run, the app downloads and verifies the recommended Whisper model, approximately 486 MB.

## Current limitation

The executable is not code-signed, so Windows may show a SmartScreen warning. See
[`docs/QA_STATUS.md`](https://github.com/aaronjnichols/cursor-dictation/blob/v0.1.1/docs/QA_STATUS.md)
for the automated checks and remaining interactive desktop test matrix.
