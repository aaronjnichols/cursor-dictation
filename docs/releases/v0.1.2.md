Cursor Dictation 0.1.2 refines the compact status overlay.

## Changed

- Increased the block grid from 12 by 7 to 24 by 14 without increasing its footprint.
- Added Warm White as the default grid palette.
- Preserved the original orange and green treatment as the optional Chamber palette.
- Replaced the sweeping transcription band with a scattered activity animation in both palettes.
- Kept the listening meter, transcription activity, and completion check aligned to the same grid.
- Added a repeatable screenshot tool for visual review of both palettes and all overlay states.

## Install

Download both release files and verify the ZIP against the `.sha256` file. Extract the complete
`Cursor Dictation` folder, then run `Cursor Dictation.exe`. The adjacent `_internal` folder must
remain beside the executable.

Choose the grid palette under **Settings > General > Dictation grid palette**.

The executable is not code-signed, so Windows may show a SmartScreen warning.
